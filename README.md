# AI Presentation Coach

A web app that helps users practice presentations using AI-powered feedback,
video recording, and script generation.

This project is being built collaboratively using Agile Scrum.

---

## Tech Stack
- React
- Vite
- JavaScript
- React Router
- GitHub
